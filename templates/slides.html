Overview & Objectives

Problem Statement & Regulations

The lab handout outlines four mandatory technical objectives:

  • Data Processing: Ingest 6 MovieLens CSV files, clean/preprocess raw attributes, and reorganize schemas into a database.
  • Database Choice: Mandatory use of MongoDB (NoSQL document model) instead of traditional relational PostgreSQL.
  • 7 Core Analytics Scenarios: Provide interactive visual answers to questions (a) through (g).
  • Role-Based Access Control: Dual-role system (Administrator & Regular User) where users can dynamically submit and update movie ratings.

System Architecture

End-to-End Technology Stack

1. Data Ingestion & ETL

Python pandas streaming pipeline directly reading compressed zip streams in chunks; processes 25M rows in ~15 seconds without disk bloat.

2. Database Layer (MongoDB)

Optimized document schemas with denormalized pre-aggregations, compound indexes, and text search indices.

3. Backend Web Framework

Python Flask 3.1 with PyMongo, Werkzeug secure password hashing (PBKDF2), role-based session auth, and REST APIs.

4. Visualization & Frontend

Chart.js 4 with responsive bar, doughnut, and histogram charts, dynamic autocomplete search, and real-time metric updates.

Slide 3 of 10
Data Engineering Innovation

Schema Reorganization & Denormalization

Per Handout Regulation 1: "Reorganize data given in 6 files into different tables with slightly varying schemas."

movies Collection

Denormalized document containing cleaned title, parsed year (int), genres array, imdbId, avgRating, ratingCount, ratingDistribution, and embedded topTags.

genre_tags Collection

Pre-aggregated cross-join between movie genres and 1.1M user tags to enable sub-millisecond retrieval of the most popular tag per genre.

ratings & users Collections

Live user interaction store recording interactive rating updates, paired with hashed user authentication documents.

Performance Advantage

Eliminates slow runtime 25M row table scans; dashboard queries return in < 5 milliseconds.

Analytical Exploration (a)

Top-5 Tags by Relevance Scores

Requirement: For a particular movie, show the top-5 tags based on relevance scores from the tag genome.

  • Implementation: In load_data.py, the 15.5M genome-score matrix is streamed in movie-aligned chunks. For each movie, the top 5 relevance scores are ranked and joined with genome-tags.csv.
  • Example: For Toy Story (1995):
    • toys (relevance: 0.9992)
    • computer animation (relevance: 0.9988)
    • pixar animation (relevance: 0.9958)
    • kids and family (relevance: 0.9858)
    • animation (relevance: 0.9842)
  • Visualization: Rendered as a horizontal bar chart on the dashboard.
Slide 5 of 10
Analytical Exploration (b)

Overall & Year-wise Top 10 Movies by Average Rating

Requirement: Rank top 10 movies based on average rating, both overall and filtered by release year.

  • Statistical Safeguard: Applied minimum vote count thresholds (e.g. min 500 ratings for all-time, min 20 ratings for annual) to avoid obscure single-vote outliers skewing the top rankings.
  • Interactive Feature: A dynamic dropdown selector allows selecting any year from 1891 to 2019 or selecting "Overall".
  • Results: All-time top 10 features classics such as The Shawshank Redemption (4.41 ★), The Godfather (4.32 ★), and Pulp Fiction (4.18 ★).

Analytical Exploration (c)

Most Popular Tags Given for Each Genre

Requirement: Identify which user tag is most frequently associated with each cinematic genre.

  • ETL Computation: Exploded movie genre arrays and performed an inner join with 1,093,360 rows from tags.csv, followed by lowercasing and frequency grouping.
  • Key Insights:
    • Action: action (6,038 applications)
    • Comedy: comedy (5,784 applications)
    • Drama: atmospheric (4,578 applications)
    • Mystery: twist ending (2,867 applications)
    • Crime: dark comedy (1,813 applications)
    • Sci-Fi: sci-fi (8,634 applications)

Analytical Explorations (d) & (e)

Rating Distributions: Movie-Level & Catalog-Wide

Question (d) — Particular Movie Rating Distribution:

  • Renders the full histogram of ratings from 0.5 ★ to 5.0 ★ for the selected movie.
  • Displays live changes when the user submits or modifies their personal rating.

Question (e) — Catalog-Wide Distribution of Total Ratings:

  • Bucketed aggregation across all 62,423 movies measuring popularity count brackets: 1-9, 10-49, 50-99, 100-499, 500-999, 1,000-4,999, up to 50,000+.
  • Demonstrates typical long-tail distribution common in media consumption datasets.

Analytical Explorations (f) & (g)

Genre Releases by Year & Global Coverage

Question (f) — Highest Genre Releases for a Particular Year:

  • Aggregates movies released in a specified year, unrolls genres, and ranks counts descending.
  • For example, in 1995, Drama (314 releases) and Comedy (216 releases) led the industry.

Question (g) — Genre-wise Coverage of Movies:

  • Visualized via an interactive doughnut chart showing the catalog proportion of every genre across all 62,423 titles.
